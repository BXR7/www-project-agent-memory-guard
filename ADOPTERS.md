# Adopters

This page lists projects and organisations that use OWASP Agent Memory Guard and have agreed to be named. Each entry says only what the adopter chose to share.

Being listed is not an endorsement by OWASP, by this project or by the adopter's organisation, and it doesn't mean a production deployment unless the entry says so.

## Add yourself

Open a pull request that adds a row to the table below, or open an issue titled `Adopter: <name> — <framework>` with the details and a maintainer will add the row for you. Please include:

- the organisation or project name, with a link if it's public;
- how you use Agent Memory Guard (for example, guarding an agent's long-term memory, scanning memory files in CI, or evaluation and research);
- the version and the framework or memory store, if you're happy to share them;
- when you started (month and year).

You can change or remove your entry at any time with a pull request or an issue.
